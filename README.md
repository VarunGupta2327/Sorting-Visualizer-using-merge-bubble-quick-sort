📊 Sorting Algorithm Visualizer

A web-based interactive sorting visualizer that demonstrates how popular sorting algorithms work in real time.
The project visually represents array elements as bars and shows the step-by-step process of sorting while also providing algorithm explanations, sound feedback, and complexity comparison.

This project helps students and developers understand sorting algorithms in an intuitive and visual way.

🚀 Features

✅ Real-time Sorting Visualization
Watch how elements move and rearrange during sorting.

✅ Multiple Algorithms

Merge Sort
Bubble Sort
Quick Sort

✅ Step-by-Step Explanation Panel
Displays the current operation being performed by the algorithm.

✅ Complexity Graph
A visual comparison of algorithm performance and efficiency.

✅ Interactive Controls

Generate Random Array
Choose Sorting Algorithm
Start Sorting

✅ Sound Feedback 🎹
Sound is played during comparisons and swaps to make the visualization more interactive.

🧠 Algorithms Included
🔹 Merge Sort

A divide-and-conquer algorithm that splits the array into smaller parts, sorts them, and merges them back together.

Time Complexity:

Best Case: O(n log n)
Average Case: O(n log n)
Worst Case: O(n log n)
🔹 Bubble Sort

A simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

Best Case: O(n)
Average Case: O(n²)
Worst Case: O(n²)
🔹 Quick Sort

A fast divide-and-conquer algorithm that selects a pivot element and partitions the array around it.

Best Case: O(n log n)
Average Case: O(n log n)
Worst Case: O(n²)
